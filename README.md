# 🛒 Market CRUD – Proyecto de Algoritmos

Proyecto académico desarrollado en Python que simula la **creación de un market (tienda)**, implementando un **CRUD** (Crear, Leer, Actualizar y Eliminar) para la gestión de datos.

Este proyecto fue realizado como parte de la asignatura **Algoritmos**, con el objetivo de aplicar estructuras de datos, control de flujo y lógica de programación.

---

## 📌 Funcionalidades

El sistema permite:

- ✅ **Crear** registros (clientes / productos / pedidos)
- 📄 **Mostrar** registros almacenados
- 🔍 **Consultar** un registro específico
- ✏️ **Actualizar** información existente
- 🗑️ **Eliminar** registros
- 🧠 Uso de **estructuras de datos** (diccionarios y listas)
- 📋 Menú interactivo por consola
